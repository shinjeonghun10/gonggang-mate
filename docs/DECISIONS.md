### 4번 상세 (채팅 요청·수락)
1. 메인(S05)에서 카테고리를 고르면 해당 카테고리 화면(S07)으로 넘어간다.
2. S07에 **매칭 목록**이 바 형태로 뜬다. 각 바에 **말풍선 버튼**이 있다.
3. 말풍선 버튼을 누르면 방장에게 **채팅 요청**이 간다. 요청한 사람에게는 "요청을 보냈어요" 상태가 보인다.
4. 방장이 채팅방(S12)에서 **수락/거절**한다. 수락되면 요청한 사람이 채팅방에 입장하고 시스템 메시지가 올라간다.
5. 방장이 **약속 확정**(S14)을 누르면 그 게시물은 **매칭 목록에서 내려간다.** 대기 중인 요청은 자동으로 거절된다.
6. 참여자가 20명(방장 포함)이 되면 말풍선 버튼이 비활성된다.
7. 약속 확정 시점의 채팅방 참여자 전원이 약속 참여자가 된다(기존과 같음).

## 개발 방식

- **기능 먼저 구현**하고, 디자인은 나중에 디자인팀의 피그마 스크린샷을 받아 반영한다.
- 지금은 화면을 예쁘게 다듬는 데 시간을 쓰지 않는다. 대신 나중에 디자인을 쉽게 바꿀 수 있게:
  - 색상·글자 크기·간격은 `theme.ts` 값만 쓴다.
  - 버튼·아바타 등은 공통 부품(`src/components`)을 쓴다. 부품 모양을 바꾸면 모든 화면에 한 번에 반영된다.
  - 화면 파일 안에서 데이터 처리(불러오기, 저장)와 화면 그리기를 섞지 않는다. 데이터는 `src/api/` 함수로 받는다.
